# Marketing-Campaign-and-Customer-Behaviour-Analysis-with-Python
This project presents an end-to-end Exploratory Data Analysis (EDA) of customer marketing data to understand customer demographics, purchasing behaviour, campaign engagement, and the factors associated with successful marketing responses.
The analysis was conducted using Python, Pandas, NumPy, Matplotlib, and Seaborn, following a structured data analytics workflow from data understanding and cleaning through to business insights and recommendations.
